# ✅ TaskMate – Automated Task Management & Testing Platform

TaskMate is a full-stack **Task Management application** built with automated testing and CI/CD integration.

The project focuses on developing a task management system while implementing professional software testing practices using **Selenium, Cypress, JMeter, and Jenkins**.

This project demonstrates frontend development, backend integration, automated testing, performance testing, and continuous integration workflow.

---

# 🚀 Project Objective

The objective of TaskMate is to build a productivity-focused task management application that allows users to:

- Create and manage tasks
- Track task progress
- Organize daily activities
- Test application functionality automatically
- Validate performance and reliability through testing frameworks

# ▶️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/rairoshni2005/TaskMate.git
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Flask Application

```bash
python app.py
```

---

## Run Cypress Tests

```bash
npx cypress open
```

---

## Run Selenium Tests

```bash
python selenium-test-file.py
```
